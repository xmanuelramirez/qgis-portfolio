## What's inside

A single-page portfolio across three fields that feed each other: AI benchmarks and evaluation, Earth sciences, and water resources engineering. It is one self-contained HTML file — no backend, no build step.

### Selected work

| Field | Project | What it is |
|---|---|---|
| AI | Scientific benchmark authoring | Self-contained Python task packages with a seeded generator, an independent reference solution, a second solution route and a sealed verifier |
| AI | Adversarial difficulty calibration | Blind trials against frontier models, with shortcut and fabricated-value probes, before a task ships |
| AI | Quantitative benchmark packages | Prompts, golden responses, grading guidance and input files, audited across artifacts |
| Earth sciences | Rainfall monitoring and 3-day forecast | LightGBM hurdle model over 21 stations under leak-free walk-forward validation |
| Earth sciences | Satellite observatory | Sentinel-2, Landsat 8/9 and Sentinel-1 read from STAC catalogs and processed in the browser |
| Water resources | Probabilistic reservoir storage forecast | 2,000-member Monte Carlo ensemble by seasonal block bootstrap |
| Water resources | Watershed delineation to design discharge | Curve numbers, IDF curves, six time-of-concentration formulas and the SCS unit hydrograph |
| Water resources | Urban stream capacity and hydraulic sectorization | 0.5 m LiDAR terrain models, cross-section profiling and QGIS Atlas map series |
